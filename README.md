# 有権者イデオロギーと政党システムの共変動 —— 2025〜2026年 日本の連立再編を事例として

> **研究は進行中です。** このリポジトリは途中経過を公開しています。結果や方法は今後変わることがあります。
> 進み具合は下の「何を作っているか」を見てください。

## この研究で知りたいこと

### 何が起きたか

2025年から2026年にかけて、日本の政党の組み合わせが大きく変わりました。

| 時期 | 出来事 |
|---|---|
| 2025年7月 | 参院選(**再編の前**) |
| 2025年10月 | 公明党が、26年続いた自民党との連立を離脱。自民党と日本維新の会が連立で合意し(維新は閣外協力)、高市内閣が発足 |
| 2026年1月 | 立憲民主党と公明党が合流し、「中道改革連合」を結成 |
| 2026年2月 | 衆院選(**再編の後**) |

### 問い

1. **政党の立場は動いたか**:再編の前と後で、各党の政策の立場(安全保障・憲法・経済など)は変わったか。
   たとえば、連立に加わった維新は自民党に近づいたか。公明党と立憲民主党は、合流の前にどれくらい離れていて、合流後の中道改革連合はどこに位置するか。
2. **どの争点で動いたか**:立場が動いたとすれば、すべての争点で動いたのか、一部の争点だけか。
3. **有権者との関係**:政党の位置の変化と、有権者の考え方(イデオロギー)の分布は、どう対応しているか。

### どうやって測るか

**2種類のデータ**を、**3つの方法**で測り、結果を比べます。

| データ | 中身 | 役割 |
|---|---|---|
| **選挙公約(マニフェスト)** | 2025年参院選・2026年衆院選の、全党の公約 | 主なデータ。同じ種類の文書を、再編の前と後で比べられる |
| **国会会議録** | 2025年1月〜2026年7月の、約8.8万件の発言 | 補助のデータ。2つの選挙の間の、議員の発言の変化を見る |

| 方法 | どう測るか | 選挙公約 | 国会会議録 |
|---|---|---|---|
| **LLM による判定**(主な方法) | 政策・発言1つずつに、争点と立場のラベルを付けて集計する。自分で付けたラベルと比べて正しさを確かめる(κ係数) | 完了(試験用で κ: 種類 0.70・争点 0.72・立場 0.44。党 × 争点の平均の相関 0.82) | これから(争点を絞る) |
| **Wordscores** | 位置がわかっている文書を基準にして、単語の使い方から各党の位置を推定する。政治学で広く使われてきた方法(Laver, Benoit & Garry 2003) | これから | これから |
| **日本語 BERT** | 文をベクトルにして、「右寄り − 左寄り」の向きに沿った位置を測る | これから | **試した → 立場を安定して取り出せなかった**(下の「これまでの結果」) |

3つの方法を使うのは、それぞれ得意・不得意があるためです。
LLM は文の意味を読めますが、間違いや書き足しをすることがあります。Wordscores は単純で再現しやすい一方、言葉の意味は見ません。BERT は意味を数値にできますが、立場以外の違い(話し方や話題)も一緒に拾ってしまいます。
同じデータを複数の方法で測り、結果が一致するか・どこで食い違うかを確かめます。

### 政策ごとに区切る方法の比較(B)

6ページ分の正解(114 政策)を作り、方法を比べました。Claude は、考える量(effort)を3段階に変えて比べています。

| 方法 | 再現率 | 適合率 | F1 | 見出しの一致 | 本文に無い行 | 6ページの料金 |
|---|---|---|---|---|---|---|
| 何もしない(元の1行 = 1政策) | 0.395 | 0.151 | 0.218 | 0.000 | 0 | ― |
| ルール(印・句点で区切る) | 0.912 | 0.889 | 0.900 | 0.505 | 1 | ― |
| Claude Sonnet 5(effort: low) | 0.921 | 0.913 | 0.917 | 0.684 | 4 | $0.09 |
| **Claude Sonnet 5(effort: medium)← 採用** | **1.000** | **0.966** | **0.983** | **0.902** | 3 | **$0.20** |
| Claude Sonnet 5(effort: high・初期値) | 1.000 | 0.966 | 0.983 | 0.833 | 2 | $0.31 |

- **effort を medium にした理由**: Claude の料金の大部分は、答える前に「考える」分(high では出力の約8割)です。考える量を減らすと安くなりますが、low では F1 がルールとほとんど変わらないところまで落ちました。medium は high と F1 が同じ(ページ別にも同じ)で、料金は約3分の2だったため、medium を選びました。
- 見出しの一致は medium の方が high より高く出ましたが、どの設定も1回ずつしか試していないため、この差が偶然の範囲かどうかは分かりません。言えるのは「medium でも質は落ちなかった」までです。

- 6ページのうち、Claude が正解づくりに関わっていない2ページ(維新 p7・れいわ p45)だけで見ても、medium は 46 政策すべて一致(F1 1.00)、見出しは 46 中 41 一致でした。

### 立場の判定(C)

**決まり(コードブック)**

政策1つずつに、3つのラベルを付けます。決まりは `data/external/codebook.md`(版 0.4.1)にまとめ、人が付けるときも LLM が付けるときも同じ決まりを使います。

| ラベル | 値 |
|---|---|
| 種類(kind) | 約束 / 説明 / 政策でない |
| 争点・話題(topic) | 立場を付ける8つの争点(安全保障・憲法・消費税・財政・社会保障・外国人・ジェンダー・エネルギー)か、話題の量だけ数える15の話題 |
| 立場(stance) | 8つの争点のときだけ +1 / −1 / 0(例: 安全保障 +1 = 防衛力を強める) |

**人が付けた正解(200行)**

- 4,083 政策から、目次のページと同じ文の2回目以降を除き、200行を乱数で選びました。党 × 選挙(21組)ごとに、行数の平方根に比べて数を決めています(行の多い党にかたよらないように)。また、8つの争点の言葉を含む行と含まない行から半分ずつ選んでいます。
- 200行を、**調整用100行**(決まりとプロンプトを直すのに使う)と**試験用100行**(最後に1回だけ測る)に分けました。
- 正解は私1人が付けました。党と選挙は見えないようにして付けています。迷った行には印を付けました(48行)。
- コード: `scripts/14_stance_sample.py`。正解: `data/external/stance_gold/`

**LLM の判定と、正解との一致度**

Claude Sonnet 5(effort: medium)に、正解と同じ見出しと文だけを渡しました(党と選挙は渡しません)。コードブックの全文を前置きに入れ、20行ずつ JSON で答えさせています。一致度は Cohen の κ で測りました(0 = 偶然と同じ、1 = 完全に一致)。

| 全部の行 | v1 調整用 | v2 調整用 | v2 調整用(2回目) | **v2.1 試験用** |
|---|---|---|---|---|
| 種類 κ | 0.804 | 0.976 | 0.929 | **0.700** |
| 争点・話題 κ | 0.590 | 0.929 | 0.906 | **0.723** |
| 立場 κ(争点が違えば外れ) | 0.398 | 0.706 | 0.706 | **0.435** |
| 立場 κ(争点が合った行だけ) | 0.755 | 0.812 | 0.840 | **0.699** |
| 料金(100行) | $0.119 | $0.137 | $0.126 | $0.130 |

- **v1 → v2**: v1 の調整用で食い違った行を1行ずつ読み、(1)すでに書いてある決まりに照らして正解の付け間違いだった行を直し、(2)正解を付けるときに私が使っていたのにコードブックに書いていなかった決まりを書き足しました(例: 自然災害への備えは防災、賃金は労働・賃金、政府に「〜を求めます」と書いた行も約束)。調整用の正解は28行を直しました。**Claude の答えに合わせて正解を変えることはしていません**。直した行と理由はすべて `data/external/stance_gold/gold_changes.csv` に残しています。
- **同じ条件でもう1回(v2 の2回目)**: Claude の答えが変わったのは100行中5行でしたが、種類の κ は 0.976 → 0.929 と動きました。100行では、1〜2行の違いで κ が 0.03〜0.05 動きます。**0.05 未満の差は意味のある差として読みません**。
- **試験用を使う前の見直し**: 新しく書いた決まりに当たる試験用の行(34行)を、Claude の試験用の答えを見ずに決まりに照らして見直し、8行を直しました。このとき決まりを1つ足しています(自衛隊の組織・任務を変える行は、災害対応が目的でも安全保障)。
- **試験用(v2.1)は1回だけ**測りました。この結果を見たあとは、決まりもプロンプトも正解も直していません。

**読み方**

- **試験用の点数は、調整用よりはっきり低く出ました**(立場 κ 0.706 → 0.435)。決まりを調整用の行を見ながら書いたので、調整用では合いすぎています。また、調整用だけは正解の付け間違いを直したので、試験用には正解の側の誤りも残っています。**実力として報告するのは試験用の値**です。
- 一番の弱点は**争点の選び方**です(試験用で、正解が8つの争点の行のうち、Claude が同じ争点を選んだのは67行中51行)。争点が合えば、立場の向きは κ 0.70(迷った行を除くと 0.84)まで合います。
- **1行ずつの判定は強くありませんが、党ごとにまとめるとかなり合います**。試験用で、党 × 争点の立場の平均を正解と Claude で比べると、36組で相関 0.82、+ と − の向きの一致は 86% でした(正解が2行以上ある15組だけでは相関 0.70)。この研究で使うのは党ごとの集計なので、この条件付きで、残りの行も Claude で判定することにしました。1行ずつの判定は、例として見せる以上には使いません。
- 人と Claude で読みが割れた例: 公明 2025 の「緊急事態における国会機能の維持」の節の試験用2行を、私は −1 と 0 にしました(「緊急政令への対抗として国会機能を守る」という読み)。Claude は2行とも +1(憲法改正を進める)にしました。この節は、大災害で選挙ができないときに議員任期を延ばす憲法改正を論じているので、+1 の読みも自然です。正解の側でも判断が分かれやすい行です。

**本番(全行)**

- 4,083 政策すべてを、試験用で測ったのと同じプロンプト(v2.1)で判定しました。行を乱数で混ぜて20行ずつの組にしています(試験用と同じく、色々な党の行が混ざる組にするため)。
- 結果: 約束 2,711 行・説明 822 行・政策でない 550 行。決まりに合わない答えは 0 行、答えが読めなかった組も 0。205 回で約 69 分、料金は $5.09
- 政策でないの割合(13%)は、正解の200行(8%)より多く出ています。正解の200行は目次のページと同じ文の行を除いて選んだので、目次の項目のような「政策でない」行が少ないためと考えられます(確かめてはいません)
- コード: `scripts/14_stance.py`(正解との比較)・`scripts/15_stance_all.py`(全行)。結果: `reports/stance_kappa.csv`・`reports/stance_gold_*.csv`

### 党の位置と、再編の前後の変化(D)

**決め方(結果を見る前に決めた)**

次の決め方は、全行の判定の結果を見る前に決めました。結果を見たあとで変えたのは、結果の数字が変わらない書き方の直しだけです。集計に使う行の決まりは、コードブックの「5. 集計の決まり」にあります。

- **党の位置**: 党 × 選挙 × 争点ごとの立場の平均(−1〜+1)。行の数 n と、95% の幅を一緒に出します。幅は、同じページの行は似ているので、行ではなく**ページを選び直す**ブートストラップ(1万回)で作りました。
- **行が少ない組**: 全部の組を表に残しますが、判断に使うのは5行以上の組だけです。
- **前後の変化**(両方の選挙にある9党): 動いた量 = 2026年 − 2025年。差の幅から p 値を出し、比べる組の多さを Benjamini–Hochberg 法で補正して、補正後も 0.05 未満の組だけを「動いた」とします。
- **中道改革連合**: 2026年の中道を、2025年の立憲・公明のそれぞれ(と、2党の平均を半分ずつ)と比べます。
- **話題の量**: 約束の行のうち、その話題の行の割合。前後の差と幅は見せるだけで、「動いた」の判断はしません。
- **確かめの集計**: 行の絞り方(目次・同じ文・約束と説明)を逆にした集計でも、同じ結論になるかを見ます。

**結果**

| | 主な集計 | 確かめの集計 |
|---|---|---|
| 党 × 選挙 × 争点の組(5行以上) | 143(75) | 140(63) |
| 前後を比べた組(判断に使う) | 56(26) | 55(21) |
| **補正後に「動いた」組** | **0** | **0** |
| 補正しない場合 | 1 | 1 |
| 線引きを3行 / 10行にした場合 | 2 / 0 | 2 / 0 |

- 補正しない場合の1組は、れいわの社会保障です(+0.90 → +0.47、差の幅 −0.70〜−0.08、p = 0.018)。26組で補正すると p = 0.46 で、偶然と区別できません。
- 中道改革連合は、争点ごとの行が少なく(5行以上は安全保障11・財政7・社会保障21の3つだけ)、その3つでは、立憲・公明のどちらとの差も幅が 0 をまたぎました。行が1〜4行の争点は、幅が0になるなど信頼できないので、判断に使っていません。
- 結果の表: `reports/party_position.csv`・`party_movement.csv`・`chudo_compare.csv`・`topic_share.csv`・`topic_share_change.csv`。コード: `scripts/16_party_position.py`

**読み方**

- 公約の文からは、**再編で党の立場が動いたとは言えませんでした**。ただし、これは「動かなかった」と同じ意味ではありません。
- 判断に使える組がもともと少なく(56組のうち26組)、しかも公約の長い党(れいわ・共産で26組中13組)に偏っています。研究で一番知りたい「連立に入った維新が自民に近づいたか」は、維新の社会保障が 36行 → 3行のように片方の行が少なく、判断できる組がほとんどありません。
- 1行ずつの判定には誤りがあり(試験用の立場 κ 0.44)、行の少ない組では幅が広くなります。**大きな動きでなければ、この方法では見分けられない**、というのが正直な結論です。
- この限界を補うために、文書全体から位置を測る方法(Wordscores・BERT)と、外の物差し(東大谷口研・朝日調査の政治家調査)との比べを次に行います。

### 国会会議録の埋め込みの診断(E)

日本語 BERT(`tohoku-nlp/bert-base-japanese-v3`)で発言をベクトルにし、立場を取り出せるかを調べました。
主な変化は「話し方のかたさ」と「話題」で、**立場を安定して取り出すことはできませんでした**。
このため、立場の主な測定には公約と LLM による判定を使い、会議録は補助にしています。
ノートブック: `notebooks/05_diagnose_embeddings.ipynb`・`notebooks/06_seed_axis_test.ipynb`

## 方法で気をつけていること

- **LLM の出力をそのまま信じない**: OCR も区切りも、人が作った正解と比べてから使う方法を決めています。
- **正解に合わせすぎない**: 区切りのルール版は採点と同じ6ページを見ながら作ったので、ほかのページでは点数が下がる可能性があります。C 段階では、調整用と試験用の正解を分け、試験用は最後に1回だけ使いました。実際に、試験用の点数は調整用よりはっきり低く出ました(上の「立場の判定(C)」)。
- **正解を Claude に合わせない**: 正解を直すのは、書いてある決まりに照らして付け間違いだった行か、新しく書いた決まりに合わせる行だけです。直した行と理由はすべて記録しています。
- **採点に使っていないページでも確かめる**: 方法を選んだページとは別のページで、点数が落ちないかを確かめています(上の「採点に使っていないページでの確かめ」)。
- **黙って失敗しない**: Claude の答えが空のときや上限で打ち切られたときは、警告を出し、その答えを使い回しません。
- **入力を途中で切らない**: 文の途中で切った入力を LLM に渡すと、見えない続きを作文することが分かったため。
- **決め方を結果の前に決める**: 党の位置の集計の決め方(線引き・補正・比べ方)は、結果を見る前に決めました。線引きを変えた場合の結果も一緒に出しています。

## 限界

- **区切りの正解は小さく、1人で作った**: 6ページ(114 政策)+ 3ページ(32 政策)だけです。正解は私1人が作り、2ページは Claude の下書きを確かめる形で作ったので、下書きに引っぱられた可能性があります。また、決まりで決められない行(コラムの枠など)は ` ??` を付けて採点から外したので、点数は難しい部分を除いた値です。6ページをどう選んだかの記録もありません。プログラムでの点検は、正解の行が本文の文字どおりかどうかだけです。
- **OCR の本文に、Claude の返事が1行入っている**: れいわ 2025 p1(写真だけのページ)の OCR の本文に、「画像には文字情報が含まれていません」という Claude の返事が入っています。このページは政策0として扱っているので、結果には影響しません。
- **立場の正解は小さく、1人で付けた**: 200行(試験用は100行)だけで、私1人が付けました。2人目の判定者がいないので、人どうしの一致度は分かりません。試験用の κ は、1〜2行の違いで 0.03〜0.05 動く程度の幅があります。
- **試験用を見てから足した決まりが1つある**: 自衛隊の組織・任務を変える行の扱いは、試験用の行(Claude の答えではなく、文と私の正解)を見て足しました。
- **公約の行が少ない**: 党 × 争点ごとの行が少なく、前後を比べて判断できる組は26組だけでした。小さな動きは見分けられません。
- **参院選と衆院選の違い**: 2025年は参院選、2026年は衆院選の公約です。書き方やその時の争点の違いが、「動いた」ように見えることがあります。
- **ブートストラップの幅は、Claude のかたよりを含まない**: 幅が表すのは偶然の揺れだけです。Claude がいつも同じ向きに読み違えるかたよりは、外の物差しとの比べで確かめます。
- **国会会議録は、後から登録される**: 同じ月の発言の件数が、調べた日によって増えていました(2026年6月: 14,669 → 15,791件)。手元のデータは最初に取得した時点のもので、2026年6・7月の発言が少し欠けています。
- **会議録の前処理の漏れ**: 委員長報告を除く決まりは「御報告申し上げ / いたし」で探しているので、「御報告します」という言い方の報告が少し残ります(`notebooks/05_diagnose_embeddings.ipynb`)。

## 動かし方

```
conda activate survey_on_party_systems      # Python 3.11
python scripts/10_download_manifestos.py
python scripts/11_extract_text.py
python scripts/12_ocr.py                     # Claude API を使う(料金がかかる)
python scripts/13_segment_eval.py            # lines・rule だけ(無料)
python scripts/13_segment_eval.py --methods lines rule claude   # Claude 版も(料金がかかる)
python scripts/13_segment.py                 # 料金の見積もりだけ
python scripts/13_segment.py --run           # 全ページを区切る(料金がかかる。答えは保存して使い回す)
python scripts/14_stance.py --run --tag v2   # 調整用100行の判定と κ(料金がかかる)
python scripts/14_stance.py --run --tag v2.1 --split test --final   # 試験用(最後に1回だけ)
python scripts/15_stance_all.py              # 全行の料金の見積もりだけ
python scripts/15_stance_all.py --run        # 全行を判定する(料金がかかる。答えは保存して使い回す)
python scripts/16_party_position.py          # 党の位置の集計(無料)
```

Claude API を使う処理には、`.env` に `ANTHROPIC_API_KEY` が必要です(`.env` は Git に入れていません)。

## データの出典

- **選挙公約**: 各政党の公式サイトで公開されている PDF・Web ページ。URL と取得日は `data/external/manifesto_sources.csv` にあります。このリポジトリに含まれる公約の文章(`data/external/ocr_gt/`・`data/external/segment_gold/`・`data/external/segment_heldout/`・`data/external/stance_gold/`)は、方法の検証のための一部の引用で、著作権は各政党にあります。
- **国会会議録**: [国会会議録検索システム](https://kokkai.ndl.go.jp/) の API(2025年1月〜2026年7月の発言)。

## AI の利用について

- 文字の読み取り(OCR)・政策の区切り・立場の判定には、Claude(Anthropic)を使っています。
- コードの作成には Claude を補助として使い、内容を確認したうえで採用しています。
- 区切りの正解6ページの作り方: 維新 p7・れいわ p45 は私が作りました。立憲 p4・共産 p6 は私が区切り、Claude が紙面の配置に合わせて並べ替え・見出しの位置を直しました。自民 p5・れいわ p13 は Claude が決まりに沿って下書きし、私が確認しました。正解の行が元の本文に一字も変えずに含まれていることは、プログラムで確かめています。採点に使っていない3ページの正解は、Claude の答えを見ずに私が作りました。
- 立場の正解200行は、私が付けました(Claude の答えは、正解を付け終えたあとに初めて見ました)。v1 の結果を見たあとで直した行は、すべて理由と一緒に `data/external/stance_gold/gold_changes.csv` に記録しています。
