# 有権者イデオロギーと政党システムの共変動 —— 2025〜2026年 日本の連立再編を事例として

> **研究は進行中です。** このリポジトリは途中経過を公開しています。結果や方法は今後変わることがあります。
> 進み具合は下の「何を作っているか」を見てください。

## この研究で知りたいこと

### 何が起きたか

2025年から2026年にかけて、日本の政党の組み合わせが大きく変わりました。

| 時期 | 出来事 |
|---|---|
| 2025年7月 | 参院選(**再編の前**) |
| 2025年10月 | 公明党が、26年続いた自民党との連立を離脱。自民党と日本維新の会が連立で合意し(維新は閣外協力)、高市内閣が発足 |
| 2026年1月 | 立憲民主党と公明党が合流し、「中道改革連合」を結成 |
| 2026年2月 | 衆院選(**再編の後**) |

### 問い

1. **政党の立場は動いたか**:再編の前と後で、各党の政策の立場(安全保障・憲法・経済など)は変わったか。
   たとえば、連立に加わった維新は自民党に近づいたか。公明党と立憲民主党は、合流の前にどれくらい離れていて、合流後の中道改革連合はどこに位置するか。
2. **どの争点で動いたか**:立場が動いたとすれば、すべての争点で動いたのか、一部の争点だけか。
3. **有権者との関係**:政党の位置の変化と、有権者の考え方(イデオロギー)の分布は、どう対応しているか。

### どうやって測るか

**2種類のデータ**を、**3つの方法**で測り、結果を比べます。

| データ | 中身 | 役割 |
|---|---|---|
| **選挙公約(マニフェスト)** | 2025年参院選・2026年衆院選の、全党の公約 | 主なデータ。同じ種類の文書を、再編の前と後で比べられる |
| **国会会議録** | 2025年1月〜2026年7月の、約8.8万件の発言 | 補助のデータ。2つの選挙の間の、議員の発言の変化を見る |

| 方法 | どう測るか | 選挙公約 | 国会会議録 |
|---|---|---|---|
| **LLM による判定**(主な方法) | 政策・発言1つずつに、争点と立場のラベルを付けて集計する。自分で付けたラベルと比べて正しさを確かめる(κ係数) | これから(政策ごとの区切りまで完了) | これから(争点を絞る) |
| **Wordscores** | 位置がわかっている文書を基準にして、単語の使い方から各党の位置を推定する。政治学で広く使われてきた方法(Laver, Benoit & Garry 2003) | これから | これから |
| **日本語 BERT** | 文をベクトルにして、「右寄り − 左寄り」の向きに沿った位置を測る | これから | **試した → 立場を安定して取り出せなかった**(下の「これまでの結果」) |

3つの方法を使うのは、それぞれ得意・不得意があるためです。
LLM は文の意味を読めますが、間違いや書き足しをすることがあります。Wordscores は単純で再現しやすい一方、言葉の意味は見ません。BERT は意味を数値にできますが、立場以外の違い(話し方や話題)も一緒に拾ってしまいます。
同じデータを複数の方法で測り、結果が一致するか・どこで食い違うかを確かめます。

## これまでの結果

### OCR の方法の比較(A)

画像になっている公約ページを、3つの方法で読み、人が作った正解(5ページ・1,525字)と比べました。

| 方法 | 文字の誤り率(CER) |
|---|---|
| Tesseract | 0.125 |
| Claude Haiku 4.5 | 0.0046 |
| **Claude Sonnet 5** | **0.0007** |

Sonnet 5 を選び、公約の 162 ページを OCR しました(費用 約 $3.7)。
コード: `scripts/12_ocr_eval.py`(比較)・`scripts/12_ocr.py`(本番)。正解: `data/external/ocr_gt/`

### 政策ごとに区切る方法の比較(B)

6ページ分の正解(114 政策)を作り、方法を比べました。Claude は、考える量(effort)を3段階に変えて比べています。

| 方法 | 再現率 | 適合率 | F1 | 見出しの一致 | 本文に無い行 | 6ページの料金 |
|---|---|---|---|---|---|---|
| 何もしない(元の1行 = 1政策) | 0.395 | 0.151 | 0.218 | 0.000 | 0 | ― |
| ルール(印・句点で区切る) | 0.912 | 0.889 | 0.900 | 0.505 | 1 | ― |
| Claude Sonnet 5(effort: low) | 0.921 | 0.913 | 0.917 | 0.684 | 4 | $0.09 |
| **Claude Sonnet 5(effort: medium)← 採用** | **1.000** | **0.966** | **0.983** | **0.902** | 3 | **$0.20** |
| Claude Sonnet 5(effort: high・初期値) | 1.000 | 0.966 | 0.983 | 0.833 | 2 | $0.31 |

- **effort を medium にした理由**: Claude の料金の大部分は、答える前に「考える」分(high では出力の約8割)です。考える量を減らすと安くなりますが、low では F1 がルールとほとんど変わらないところまで落ちました。medium は high と F1 が同じ(ページ別にも同じ)で、料金は約3分の2だったため、medium を選びました。
- 見出しの一致は medium の方が high より高く出ましたが、どの設定も1回ずつしか試していないため、この差が偶然の範囲かどうかは分かりません。言えるのは「medium でも質は落ちなかった」までです。
- 「本文に無い行」は、元の本文にそのまま現れない行です(言い換え・書き足しの検出)。Claude の該当行は、どの設定でもほとんどが立憲 p4 の図(コラム)の中の文字を並べ替えてつないだもので、本文に無いかっこや「:」を書き足していました。この図の中身は、正解では判断が難しいものとして採点から外しています。
- 本番では、全ページでこの検出を行い、該当したページを目で確かめます。
- コード: `scripts/13_segment_eval.py`・`scripts/llm_common.py`。結果: `reports/segment_eval.csv`。正解: `data/external/segment_gold/`(作り方は `_書き方.md`)

### 国会会議録の埋め込みの診断(E)

日本語 BERT(`tohoku-nlp/bert-base-japanese-v3`)で発言をベクトルにし、立場を取り出せるかを調べました。
主な変化は「話し方のかたさ」と「話題」で、**立場を安定して取り出すことはできませんでした**。
このため、立場の主な測定には公約と LLM による判定を使い、会議録は補助にしています。
ノートブック: `notebooks/05_diagnose_embeddings.ipynb`・`notebooks/06_seed_axis_test.ipynb`

## 方法で気をつけていること

- **LLM の出力をそのまま信じない**: OCR も区切りも、人が作った正解と比べてから使う方法を決めています。
- **正解に合わせすぎない**: ルール版は採点と同じ6ページを見ながら作ったので、ほかのページでは点数が下がる可能性があります。C 段階では、調整用と試験用の正解を分けます。
- **黙って失敗しない**: Claude の答えが空のときや上限で打ち切られたときは、警告を出し、その答えを使い回しません。
- **入力を途中で切らない**: 文の途中で切った入力を LLM に渡すと、見えない続きを作文することが分かったため。

## 動かし方

```
conda activate survey_on_party_systems      # Python 3.11
python scripts/10_download_manifestos.py
python scripts/11_extract_text.py
python scripts/12_ocr.py                     # Claude API を使う(料金がかかる)
python scripts/13_segment_eval.py            # lines・rule だけ(無料)
python scripts/13_segment_eval.py --methods lines rule claude   # Claude 版も(料金がかかる)
```

## AI の利用について

- 文字の読み取り(OCR)と政策の区切りには、Claude(Anthropic)を使っています。
- コードの作成には Claude を補助として使い、内容を確認したうえで採用しています。
- 区切りの正解6ページの作り方: 維新 p7・れいわ p45 は私が作りました。立憲 p4・共産 p6 は私が区切り、Claude が紙面の配置に合わせて並べ替え・見出しの位置を直しました。自民 p5・れいわ p13 は Claude が決まりに沿って下書きし、私が確認しました。正解の行が元の本文に一字も変えずに含まれていることは、プログラムで確かめています。
