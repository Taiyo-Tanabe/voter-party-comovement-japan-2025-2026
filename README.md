# 有権者イデオロギーと政党システムの共変動 —— 2025〜2026年 日本の連立再編を事例として

> **研究は進行中です。** このリポジトリは途中経過を公開しています。結果や方法は今後変わることがあります。
> 進み具合は下の「進捗」を見てください。

2025年10月、公明党が連立を離れ、自民党と日本維新の会が連立を組みました。
この再編の前後(2025年7月の参院選と、2026年2月の衆院選)で、**各党の政策の立場がどう動いたか**を、選挙公約(マニフェスト)と国会会議録から測ります。

## 何を作っているか

| 段階 | 内容 | 状態 |

| A. 公約の収集と文字の取り出し | 2回の選挙・全党の公約 PDF / Web を集め、画像のページは OCR で文字にする | 完了 |
| B. 政策ごとに区切る | 1ページの文字を「1行 = 1政策」に区切り、見出しを付ける | 方法を選んだ(本番はこれから) |
| C. 立場の判定 | 政策1つずつに、争点と立場のラベルを LLM で付け、人の判定と比べる(κ) | これから |

| F. 有権者 | 有権者調査・政治家調査との比較 | これから |

## これまでの結果

### OCR の方法の比較(A)

画像になっている公約ページを、3つの方法で読み、人が作った正解(5ページ・1,525字)と比べました。

| 方法 | 文字の誤り率(CER) |
|---|---|
| Tesseract | 0.125 |
| Claude Haiku 4.5 | 0.0046 |
| **Claude Sonnet 5** | **0.0007** |

Sonnet 5 を選び、公約の 162 ページを OCR しました(費用 約 $3.7)。
コード: `scripts/12_ocr_eval.py`(比較)・`scripts/12_ocr.py`(本番)。正解: `data/external/ocr_gt/`

### 政策ごとに区切る方法の比較(B)

6ページ分の正解(114 政策)を作り、3つの方法を比べました。

| 方法 | 再現率 | 適合率 | F1 | 見出しの一致 | 本文に無い行 |
|---|---|---|---|---|---|
| 何もしない(元の1行 = 1政策) | 0.395 | 0.151 | 0.218 | 0.000 | 0 |
| ルール(印・句点で区切る) | 0.912 | 0.889 | 0.900 | 0.505 | 1 |
| **Claude Sonnet 5** | **1.000** | **0.966** | **0.983** | **0.833** | 2 |

- 「本文に無い行」は、元の本文にそのまま現れない行です(言い換え・書き足しの検出)。Claude の2件は、図(コラム)の中の文字を並べ替えてつないだもので、うち1件は本文に無いかっこを書き足していました。
- 本番では、全ページでこの検出を行い、該当したページを目で確かめます。
- コード: `scripts/13_segment_eval.py`・`scripts/llm_common.py`。結果: `reports/segment_eval.csv`。正解: `data/external/segment_gold/`(作り方は `_書き方.md`)

### 国会会議録の埋め込みの診断(E)

日本語 BERT(`tohoku-nlp/bert-base-japanese-v3`)で発言をベクトルにし、立場を取り出せるかを調べました。
主な変化は「話し方のかたさ」と「話題」で、**立場を安定して取り出すことはできませんでした**。
このため、立場の主な測定には公約と LLM による判定を使い、会議録は補助にしています。
ノートブック: `notebooks/05_diagnose_embeddings.ipynb`・`notebooks/06_seed_axis_test.ipynb`

## 方法で気をつけていること

- **LLM の出力をそのまま信じない**: OCR も区切りも、人が作った正解と比べてから使う方法を決めています。
- **正解に合わせすぎない**: ルール版は採点と同じ6ページを見ながら作ったので、ほかのページでは点数が下がる可能性があります。C 段階では、調整用と試験用の正解を分けます。
- **黙って失敗しない**: Claude の答えが空のときや上限で打ち切られたときは、警告を出し、その答えを使い回しません。
- **入力を途中で切らない**: 文の途中で切った入力を LLM に渡すと、見えない続きを作文することが分かったため。

```

  0x_  国会会議録    01_fetch_kokkai.py → 02_preprocess.py
```

## 動かし方

```
conda activate survey_on_party_systems      # Python 3.11
python scripts/10_download_manifestos.py
python scripts/11_extract_text.py
python scripts/12_ocr.py                     # Claude API を使う(料金がかかる)
python scripts/13_segment_eval.py            # lines・rule だけ(無料)
python scripts/13_segment_eval.py --methods lines rule claude   # Claude 版も(料金がかかる)
```

Claude API を使う処理には、`.env` に `ANTHROPIC_API_KEY` が必要です(`.env` は Git に入れていません)。

## データの出典

- **選挙公約**: 各政党の公式サイトで公開されている PDF・Web ページ。URL と取得日は `data/external/manifesto_sources.csv` にあります。このリポジトリに含まれる公約の文章(`data/external/ocr_gt/`・`data/external/segment_gold/`)は、方法の検証のための一部の引用で、著作権は各政党にあります。
- **国会会議録**: [国会会議録検索システム](https://kokkai.ndl.go.jp/) の API(2025年1月〜2026年7月の発言)。

## AI の利用について

- 文字の読み取り(OCR)と政策の区切りには、Claude(Anthropic)を使っています。
- コードの作成には Claude を補助として使い、内容を確認したうえで採用しています。
- 区切りの正解6ページの作り方: 維新 p7・れいわ p45 は私が作りました。立憲 p4・共産 p6 は私が区切り、Claude が紙面の配置に合わせて並べ替え・見出しの位置を直しました。自民 p5・れいわ p13 は Claude が決まりに沿って下書きし、私が確認しました。正解の行が元の本文に一字も変えずに含まれていることは、プログラムで確かめています。
